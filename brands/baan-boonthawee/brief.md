# Brief: Baan Boonthawee / บ้านบุญทวี (อพาร์ทเม้น)

> สร้างจาก `.claude/skills/graphic-designer/references/brief-questions.md` · ผู้ใช้ตอบบรีฟเมื่อ: 2026-11-24

## แกนแบรนด์
- **ชื่อ (ไทย / อังกฤษ):** บ้านบุญทวี / Baan Boonthawee
- **ความหมายหรือที่มาของชื่อ:** ยังไม่ได้ยืนยัน (ดูสมมติฐาน) ไม่นำความหมายชื่อมาตีความในสัญลักษณ์
- **ธุรกิจ / สินค้า / จุดเด่น:** อพาร์ทเม้นให้เช่า เครือเดียวกับ บุญทวี คาเฟ่ (`brands/cafe-boonthawee/`)
- **กลุ่มลูกค้า:** คนทำงาน
- **บุคลิก 3 คำ:** อบอุ่น · เหมือนกลับบ้าน · ไว้ใจได้ (สมมติฐาน จากคำว่า "สีอบอุ่น")
- **ห้ามมี:** ไอคอนสามัญของธุรกิจ (หลังคาสามเหลี่ยม + กุญแจ), ฟอนต์ sans เหลี่ยมแข็ง, หน้าตาแฟรนไชส์ (จากรสนิยมทั่วไปใน `refs/style-library.md` §10)
- **ความสัมพันธ์กับคาเฟ่:** เชื่อมแค่ชื่อและสี ไม่ใช้ตัว b ก้อนบวมของคาเฟ่
- **สิ่งที่มีอยู่แล้ว:** สีคาเฟ่ (ส้มอิฐ #E8573A, มะกอก #8A9A5B, ครีม #F3EEE6) ใช้เป็นสะพานเชื่อมเครือ

## สี
- ผู้ใช้เลือกผสม 2 โทน: **ดินเผา/อิฐ + ครีม** และ **น้ำตาลไม้ + เขียวมะกอก**

## สมมติฐาน (ข้อที่ผู้ใช้ยังไม่ตอบ)
- ความหมายชื่อ "บุญทวี" (เดิมตีความว่า บุญ = บุญกุศล, ทวี = เพิ่มพูน)
- บุคลิก 3 คำ
- ไม่ต้องมีสโลแกนใต้โลโก้; คำอธิบาย "Apartment / อพาร์ทเม้น" ใส่เป็นบรรทัดเล็กได้
- ยังไม่ต้องการ motion
