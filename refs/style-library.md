## 3. Cafe board (boonthawee) — "raw minimal + mascot กวน"

**Space:** ปูนเปลือย, บล็อกช่องลม/บล็อกคอนกรีตเป็นที่นั่ง, ไม้อ่อน, พาเลทไม้, กระเบื้องขาวตาราง, ไฟเพนแดนต์, กระจกบานกว้าง, ร้านหน้าแคบสไตล์ตรอกเกาหลี/ญี่ปุ่น, ต้นไม้ในกระถาง
**Signage:** กล่องไฟสี่เหลี่ยมเล็ก (the coffee.), ป้ายสามเหลี่ยมยื่นออก (SHELTER), ป้ายห้อยลอนสังกะสี (HOT ASIAN BUNS), wordmark lowercase บนแผ่นไม้ (commune/coffee)
**Illustration:** Baht. — ถ้วยมีแขนกอดตัวเอง; แก้ว take-away มีตาเดิน; แก้วคว่ำกาแฟหก — ลายเส้นดำหนาไม่สม่ำเสมอ มุกตลก; SOLTO — นกกระจอกเทศเส้นแดงกับตัวอักษรดำ

→ สำหรับคาเฟ่: wordmark lowercase เรียบ + mascot ลายเส้น 1 ตัวเป็นตัวสร้างคาแรกเตอร์, สีปูน/ไม้/ดำ + accent 1 สี, ทดสอบบนกล่องไฟ แก้วกระดาษ สติกเกอร์

## 4. Photo run board — "energy ของ motion"

- มุมกล้อง: fisheye ใกล้หน้า, worm's-eye จากพื้น, คนกระโดดข้ามกล้อง, กลุ่มคนก้มมองกล้อง
- แสง: แดดแรง + direct flash, ท้องฟ้าฟ้าอิ่มสี, golden hour ทะเลทราย
- เทคนิค: motion blur / ghosting, slow shutter, ฟิล์มเกรน, หยดน้ำบนกระจก
- คอนเทนต์: run club, เพื่อนกลุ่ม, candid ไม่โพส, เหงื่อ, ราดน้ำบนหัว
- Type: headline sans หนาสีขาวทับภาพ, โลโก้เล็กมุมเฟรม (BANDIT, NERDY., RUN)
- สี wardrobe: น้ำตาล ดำ แดงเลือดหมู ชมพู ครีม

→ ใช้เป็นภาษาภาพของ motion: speed ramp, hard cut, fisheye warp, blur trail, grain, logo โผล่มุมเฟรมเล็กๆ

## 5. สิ่งที่ทุกบอร์ดมีร่วมกัน

- **ความมั่นใจของฟอร์มเดียว** — ไม่มีโลโก้ไหนใช้องค์ประกอบเกิน 2 ชิ้น
- **พื้นที่ว่างเยอะ** — พรีเซนต์กลางเฟรม รอบตัวโล่ง
- **มนุษย์ + ความสนุก** — แม้งานจะ minimal แต่มีอารมณ์ขันหรือพลังเสมอ
- **Texture จริง** — กระดาษ ปูน grain ฟิล์ม ไม่ใช่ดิจิทัลเกลี้ยง

| Streetwear / event | Y2K sticker set: ดาว, scribble, สัตว์ขอบหยัก | ดำ / แดง `#E5242A` |

## 10. รสนิยมทั่วไปของผู้ใช้ (จาก feedback)
ใช้เมื่อบรีฟไม่ได้บอกทิศทาง ข้อมูลเจาะจงแต่ละแบรนด์อยู่ใน `brands/*/feedback-log.md`
- **ชอบ:** ฟอร์มหนาแบบก้อน (blob b ของ boonthawee), ภาพประกอบตัวละครที่มีมุก, ภาพพิมพ์วินเทจ ลายหมึก เนื้อกระดาษ, palette 2–3 สีจาก ref, งานที่อ้าง ref ได้ชัด
- **สีที่ชอบ (บ้านบุญทวี รอบ 6):** อบอุ่น มินิมอล หรู — tonal 2 สีหม่น + accent แชมเปญ/ทองเหลือง; ไม่ชอบ palette หลายสีที่อิ่มตัว (ดินเผาสด + มะกอก + เหลืองสด)
- **บ้านบุญทวี รอบ 8:** ชอบเส้นหมึกสั่นแบบลายมือ/ภาพพิมพ์ และขาวดำ ว่า "เรียบ แพง" มากกว่า palette ทองเหลือง/มอคค่า
- **ไม่ชอบ:** ไอคอนสามัญของธุรกิจ (เครื่องซักผ้าตรงๆ, เครื่องหมายถูกในวงกลม), สีสามัญของวงการ (น้ำเงิน+เหลืองร้านซักผ้า), ฟอนต์ sans เหลี่ยมแข็ง (Kanit ตัวพิมพ์ใหญ่) กับงานภาพประกอบ, ตัวอักษรเด้ง, มาสคอตการ์ตูนเด็ก (เป็ดใส่เสื้อ), งานที่ดูเหมือนแอปหรือแฟรนไชส์
- **วิธีทำงานที่ต้องการ:** ถามบรีฟละเอียดก่อน, ส่งดราฟต์ก่อนทำจริง, ส่งเป็นไฟล์รูป, ใช้ต่อใน Adobe
