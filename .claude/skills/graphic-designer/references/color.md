## 1. วิธีสร้าง palette จากบรีฟและ ref
1. **ดูดสีจาก ref ก่อน**: เปิดรูป ref ของแบรนด์ หยิบสีพื้น สีหลัก และสีเน้นที่ซ้ำกันหลาย pin (ใช้ Python/PIL หาสีเด่นได้ถ้าจำเป็น)
2. **กรองด้วยบุคลิกแบรนด์**: อบอุ่น→ครีม ส้ม น้ำตาล, สะอาด→ขาวหม่น ฟ้าหม่น, พรีเมียม→ดำ ครีม ทอง/เงินหม่น, สนุก→สีอิ่มตัดกัน 2 สี, ย้อนยุค→สีหม่นลงจากสีสด (เหลืองมัสตาร์ด, เขียวเข้ม, น้ำเงินหมึก, แดงอิฐ)
3. **เลี่ยงสีสามัญของวงการ** ถ้าบรีฟไม่ได้ขอ: ร้านซักผ้า=น้ำเงินสด+ฟ้า, คาเฟ่=น้ำตาลกาแฟ, คลินิก=ฟ้าขาว, ออร์แกนิก=เขียวใบไม้ ลองหาสีที่ทำให้แบรนด์ต่างแต่ยังสื่อความหมายได้ (เช่น ร้านซักผ้าใช้ฟ้าหม่นแบบผ้าฝ้ายแทนน้ำเงินสด)
4. **ทดสอบบนงานจริง**: วางโลโก้และ layout บนทุกสีพื้นใน palette ก่อนสรุป

## 2. โครงสร้าง palette และสัดส่วน
| บทบาท | จำนวน | สัดส่วนบนงาน | ตัวอย่าง |
|---|---|---|---|
| สีพื้น (neutral) | 1–2 | ~60% | ครีม, ขาวหม่น, เทากระดาษ, ดำเขียว |
| สีหลัก (primary) | 1 | ~30% | สีที่คนจำแบรนด์ได้ |
| สีเน้น (accent) | 1 | ~10% | ใช้กับปุ่ม, ราคา, จุดที่ต้องเห็นก่อน |
| สีรอง (optional) | 1–2 | น้อยมาก | แยกรส/หมวดสินค้า |

- โลโก้ควรใช้ได้ด้วย **สีเดียว** (ขาวบนเข้ม / เข้มบนขาว) ก่อนจะมีเวอร์ชันหลายสี
- มาสคอตใช้ได้ 3–4 สี แต่ต้องมีเวอร์ชันสีเดียวสำหรับตราประทับและงานพิมพ์ถูก

## 3. Contrast และการอ่านออก
- ตัวหนังสือเนื้อหา: contrast อย่างน้อย 4.5:1, หัวข้อใหญ่อย่างน้อย 3:1 (คำนวณ WCAG ด้วยสคริปต์สั้นๆ ได้)
- ระวังคู่ที่ดูสวยแต่อ่านยาก: ครีมบนเหลือง, ส้มบนแดง, ฟ้าหม่นบนเทา
- รายละเอียดเล็ก (ฟองสบู่ขาว, เส้นบาง) บนพื้นสีอ่อนจะหาย ต้องเปลี่ยนเป็นสีเข้มในเวอร์ชันพื้นอ่อน
- ดูงานที่ขนาดเล็ก (48px) และแบบขาวดำ ถ้ายังแยกส่วนได้ แปลว่าค่าน้ำหนักสี (value) ดี

## 4. สูตรคู่สีที่ใช้ได้จริง
| สูตร | วิธี | เหมาะกับ |
|---|---|---|
| Mono + 1 accent | ดำ/ครีม + สีสด 1 สี | โลโก้มินิมอล, สตูดิโอ, คาเฟ่ |
| Complementary หม่น | สีตรงข้ามกันแต่ลดความสด (น้ำเงินหมึก + เหลืองมัสตาร์ด) | วินเทจ, ฉลาก |
| Analogous | สีติดกันบนวงล้อ (เขียวเข้ม + มะกอก + ครีม) | ธรรมชาติ, อบอุ่น |
| Dark field | พื้นเข้ม + ครีม + accent ส้ม | ภาพประกอบตัวละคร (แบบฝูงห่าน) |
| Color-block system | 4 สีพื้น ใช้โลโก้ตัวเดียว สลับพื้น | แบรนด์ที่มีหลายสินค้า (แบบ ref Beyond) |

## 5. สีในงานพิมพ์
- ระบุทุกสีเป็น HEX + RGB (จอ) + CMYK (พิมพ์) ส่วน Pantone ให้ใส่เป็น "ค่าใกล้เคียง ต้องเทียบกับ swatch จริง" เพราะการแปลงไม่แม่นยำ
- สีหม่นและสีเข้มเพี้ยนน้อยกว่าสีสดเมื่อพิมพ์ ส่วนน้ำเงินสด/ส้มนีออน/เขียวสดเพี้ยนมากใน CMYK
- ดำสำหรับพื้นใหญ่ใช้ Rich black (C60 M40 Y40 K100) ส่วนตัวหนังสือเล็กใช้ K100 อย่างเดียว
- รายละเอียดเพิ่มเติมดู `print-production.md`
