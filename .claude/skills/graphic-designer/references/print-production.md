# Print Production: เตรียมไฟล์งานพิมพ์

## สารบัญ
1. เช็กลิสต์ไฟล์ส่งโรงพิมพ์
2. สีในงานพิมพ์
3. ขนาดและวัสดุที่ใช้บ่อย
4. ไฟล์โลโก้ที่ต้องส่งมอบ

---

## 1. เช็กลิสต์ไฟล์ส่งโรงพิมพ์
- [ ] ขนาดจริงของชิ้นงาน (trim) ถูกต้อง
- [ ] Bleed 3 มม. รอบด้าน (ป้ายไวนิลใหญ่ถามโรงพิมพ์ มักใช้ 2–5 ซม. สำหรับพับเจาะตาไก่)
- [ ] Safe area: ตัวหนังสือและโลโก้ห่างขอบตัดอย่างน้อย 3–5 มม.
- [ ] โหมดสี CMYK, ภาพ 300 dpi ที่ขนาดจริง (ป้ายใหญ่ดูจากไกลใช้ 100–150 dpi ได้)
- [ ] ตัวหนังสือ Create Outlines หรือแนบฟอนต์ (ฟอนต์ไทยฟรีบางตัวห้ามฝังเชิงพาณิชย์ ให้เช็ก license)
- [ ] ไดคัท/ไวท์อิงค์/ฟอยล์ แยก layer เป็น spot color พร้อมชื่อ
- [ ] Export PDF/X-1a หรือ PDF/X-4 ตามที่โรงพิมพ์ต้องการ
- [ ] ตรวจคำสะกด ตัวเลข ราคา เบอร์โทร QR (สแกนทดสอบ) กับผู้ใช้ก่อนส่ง
- [ ] ขอ proof จากโรงพิมพ์ก่อนพิมพ์จริง โดยเฉพาะงานที่สีสำคัญ

## 2. สีในงานพิมพ์
- สีสดบนจอ (RGB) จะหม่นลงเมื่อพิมพ์ CMYK โดยเฉพาะน้ำเงินสด เขียวสด ส้มสะท้อนแสง
- Rich black สำหรับพื้นดำใหญ่: C60 M40 Y40 K100, ตัวหนังสือเล็กใช้ K100
- สีแบรนด์ที่สำคัญมาก ให้ใช้ Pantone (spot) และเทียบกับ swatch จริง
- พิมพ์บนกระดาษคราฟต์หรือพื้นสี: สีจะเข้มและหม่นลง ต้องใช้ white ink ก่อนถ้าต้องการสีสว่าง

## 3. ขนาดและวัสดุที่ใช้บ่อย
| งาน | ขนาด/วัสดุที่พบบ่อย |
|---|---|
| สติกเกอร์โลโก้ | PVC ขาว/ใส ไดคัทตามรูป 5–8 ซม. |
| ฉลากขวด | กระดาษอาร์ตมัน/PP กันน้ำ, วัดเส้นรอบวงจริงก่อนออกแบบ |
| แก้วกระดาษ | ขอ template ไดคัทจากโรงงาน (รูปพัด) |
| ถุงผ้า | สกรีน 1–2 สี, พื้นที่พิมพ์ประมาณ 25×30 ซม. |
| ป้ายกล่องไฟ | อะคริลิกขาวขุ่น + สติกเกอร์สี หรือพิมพ์ UV |
| ป้ายไวนิล | 100–150 dpi ที่ขนาดจริง, เผื่อขอบเจาะตาไก่ |
| เมนู | อาร์ตการ์ด 260–300 แกรม เคลือบด้าน |

## 4. ไฟล์โลโก้ที่ต้องส่งมอบ
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| .ai / .eps / .svg (vector) | งานพิมพ์ทุกขนาด, ส่งโรงพิมพ์ |
| .pdf | ส่งต่อให้คนที่ไม่มี Illustrator |
| .png พื้นโปร่ง (500, 1000, 3000 px) | โซเชียล, เอกสาร, วิดีโอ |
| .jpg พื้นสี | ไอคอนโปรไฟล์ |
| เวอร์ชัน | หลัก (สี), สีเดียวเข้ม, สีเดียวขาว, symbol อย่างเดียว, wordmark อย่างเดียว, แนวนอน, แนวตั้ง |
