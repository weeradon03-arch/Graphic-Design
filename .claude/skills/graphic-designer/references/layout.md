# Layout & Artwork: การจัดวาง

## สารบัญ
1. หลักการจัดวาง
2. Grid
3. ลำดับความสำคัญ (hierarchy)
4. สูตรจัดวางตามประเภทงาน
5. ขนาดสื่อมาตรฐาน
6. Artwork (AW) ส่งผลิต

---

## 1. หลักการจัดวาง
- **จุดเดียวที่เห็นก่อน**: ทุกชิ้นงานต้องมี focal point เดียว (ภาพ, หัวข้อ, หรือโลโก้) ที่ใหญ่กว่าส่วนอื่นชัดเจน อย่าให้ 3 อย่างใหญ่เท่ากัน
- **พื้นที่ว่างคือส่วนหนึ่งของงาน**: เว้นขอบอย่างน้อย 5–8% ของด้านสั้น ref ส่วนใหญ่ของผู้ใช้ใช้พื้นที่ว่างเยอะ
- **จัดชิด (alignment)**: เลือกแกนเดียว (ซ้าย, กลาง) ต่อหนึ่งกลุ่มข้อความ ห้ามผสมกลางกับซ้ายในกลุ่มเดียวกัน
- **จัดกลุ่ม (proximity)**: ข้อมูลที่เกี่ยวกันอยู่ใกล้กัน กลุ่มที่ต่างกันเว้นห่างกันชัดเจน
- **ทำซ้ำ (repetition)**: ใช้ระยะ ขนาดฟอนต์ และสีชุดเดิมทั้งชิ้น ใช้ spacing scale 4/8 (8, 16, 24, 32, 48, 64…)
- **ตัดกัน (contrast)**: ขนาดตัวหนังสือหัวข้อกับเนื้อหาควรต่างกันอย่างน้อย 2–3 เท่า

## 2. Grid
| งาน | Grid แนะนำ |
|---|---|
| โปสเตอร์ A-series | 6 คอลัมน์, margin 6–8% |
| IG post 4:5 | 4 คอลัมน์, margin 64–80px บน 1080 |
| Story/Reels 9:16 | safe zone บน 250px ล่าง 350px |
| เมนู | 2–3 คอลัมน์ + baseline grid ตามขนาดตัวหนังสือเนื้อหา |
| ฉลาก | แบ่งหน้าหลัก (ชื่อ, ภาพ, รส) และหน้าข้อมูล (ส่วนผสม, อย., บาร์โค้ด) |

editorial แบบ ref (FIELD/TEAM, RUN RUN RUN): ตัวหนังสือใหญ่ชนขอบ + ภาพเต็มเฟรม + ข้อความเล็กมุมจัดเป็นแถวบนสุดหรือล่างสุด

## 3. ลำดับความสำคัญ (hierarchy)
เรียงข้อมูลก่อนออกแบบเสมอ:
1. สิ่งที่ต้องเห็นใน 1 วินาที (หัวข้อ หรือภาพหลัก)
2. สิ่งที่ทำให้ตัดสินใจ (ราคา, โปรโมชั่น, วันที่)
3. วิธีติดต่อหรือ action (QR, ที่อยู่, ลิงก์)
4. โลโก้และข้อมูลประกอบ

ใช้ขนาด น้ำหนัก สี และตำแหน่งแยกระดับ ไม่เกิน 3–4 ระดับในชิ้นเดียว

## 4. สูตรจัดวางตามประเภทงาน
- **โปสเตอร์ event**: ภาพหรือตัวหนังสือใหญ่ 60% → หัวข้อ → วัน/เวลา/สถานที่เป็นบล็อกเดียว → โลโก้มุมล่าง
- **โพสต์โปรโมชั่น**: สินค้าใหญ่ + ราคา/ส่วนลดเป็นจุดเน้นสี accent + CTA สั้น
- **โพสต์ประกาศ (เปิดร้าน, ปิดร้าน)**: ข้อความหลักใหญ่ + มาสคอตหรือภาพประกอบ + รายละเอียดสั้น
- **เมนู**: หมวด → รายการ → ราคา (ชิดขวาเป็นคอลัมน์เดียว) ใช้ไอคอนหรือสีแยกเมนูแนะนำ อย่าใช้เส้นจุดลากยาว
- **ป้ายหน้าร้าน**: โลโก้ใหญ่ อ่านได้จากระยะ 10–20 เมตร (ความสูงตัวอักษร ≈ 2.5 ซม. ต่อระยะอ่าน 1 เมตร) และคำอธิบายธุรกิจ 1 บรรทัด
- **ฉลาก/แพ็กเกจ**: ชื่อสินค้าและภาพต้องอ่านได้จากชั้นวางที่ระยะ 1–2 เมตร
- **การ์ดโซเชียลแบบชุด**: grid เดียวกันทุกแผ่น เปลี่ยนแค่ภาพและสี เพื่อให้ feed ดูเป็นระบบ

## 5. ขนาดสื่อมาตรฐาน
| สื่อ | ขนาด |
|---|---|
| IG post | 1080×1350 (4:5), 1080×1080 |
| IG/TikTok story, reels | 1080×1920 |
| Facebook cover | 1640×624 (ดูได้ทั้งมือถือและคอม) |
| LINE OA rich menu | 2500×1686 หรือ 2500×843 |
| LINE sticker | 370×320 ต่อชิ้น, พื้นโปร่ง |
| A4 / A3 / A2 | 21×29.7 / 29.7×42 / 42×59.4 ซม. |
| นามบัตร | 9×5.5 ซม. |
| สติกเกอร์วงกลม | 5–8 ซม. ทั่วไป |

ขนาดแพลตฟอร์มเปลี่ยนบ่อย ถ้าไม่แน่ใจให้บอกผู้ใช้เช็กอีกครั้ง

## 6. Artwork (AW) ส่งผลิต
AW = ไฟล์สุดท้ายที่ส่งให้โรงพิมพ์หรือคนผลิต ต้องมี:
- ขนาดจริง + bleed 3 มม. + safe area 3–5 มม. (ดู `print-production.md`)
- ตัวหนังสือ outline แล้ว หรือแนบฟอนต์
- ภาพ 300 dpi ที่ขนาดจริง
- สีตามโหมดงาน (CMYK สำหรับพิมพ์)
- ไดคัทอยู่ layer แยก เป็นเส้น spot color ชื่อ "DIECUT"
- ตรวจคำสะกดไทยและอังกฤษ ตัวเลข ราคา เบอร์โทร กับผู้ใช้ก่อนส่ง
