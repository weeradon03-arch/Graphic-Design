## 1. สร้างตัวละครจาก ref
1. **Silhouette ก่อน**: ตัวละครต้องจำได้จากเงาดำอย่างเดียว ถ้าเงาไม่บอกว่าเป็นตัวอะไร รายละเอียดก็ช่วยไม่ได้
2. **1 ท่า 1 มุก**: ท่าหลักต้องเล่าเรื่องของแบรนด์ในท่าเดียว (เช่น ห่านนั่งห้อยขาบนเครื่องซักผ้า, ห่านคอเป็นตัว S)
3. **ผูกกับชื่อแบรนด์**: หาจุดที่ตัวละครกลายเป็นตัวอักษรหรือความหมายของชื่อ (คอเป็น S ของ Success)
4. **ใส่สัญญาณธุรกิจผ่านของประกอบ** ไม่ใช่ผ่านไอคอนสามัญ: ถุงเท้าในปาก, ตะกร้าผ้า, ไม้หนีบ, ฟองสบู่
5. **palette จาก ref**: เช่น ref ฝูงห่าน = ตัวครีม ปาก/ตีนส้ม พื้นเขียวเข้ม รายละเอียดเป็นเส้นสีพื้น
6. **ทำหลายท่าก่อนเลือก**: ร่าง 3 ฉาก (เช่น ในอ่างฟอง, บนเครื่องซักผ้า, แบกตะกร้า) แล้วให้ผู้ใช้เลือก

## 2. ร่างด้วย SVG แบบชิ้นส่วนใช้ซ้ำ
แยกตัวละครเป็นชิ้นส่วนใน `<defs>` แล้วประกอบเป็นฉากต่างๆ ด้วย `<use>` + `transform`:
```html
<g id="gBody">…ลำตัว หาง ปีก…</g>
<g id="gNeck">…คอ หัว ปาก ตา…</g>
<g id="gLegs">…ขา ตีน…</g>
<g id="gProp">…ของประกอบ เช่น ถุงเท้า…</g>
<symbol id="scene1" viewBox="0 0 400 400">
  <use href="#gBody" transform="translate(40 30)"/> …
</symbol>
```
- ลำดับ layer สำคัญ: วาดสิ่งที่อยู่หลังก่อน (เช่น ตัวห่าน → ขอบอ่างด้านหน้า → ฟอง)
- คอยาวทำด้วย stroke หนา (`stroke-linecap="round"`) และขอบทำด้วย stroke ที่กว้างกว่าวางใต้
- ขอบหยักแบบตัดกระดาษหรือหมึก: `feTurbulence` + `feDisplacementMap` scale 3–6 ใส่ทั้งฉาก

## 3. สลับสไตล์ด้วย CSS variables
ตัวละครตัวเดียววาดได้หลายสไตล์ โดยให้ทุกสีและเส้นขอบมาจากตัวแปร:
```css
.flat { --gw:#F2EEE6; --gs:transparent; --bg:#1E3A22; --beak:#E9822B; --hatch:0 }
.ink  { --gw:#F2EEE6; --gs:#1B2547;     --bg:#1B2547; --beak:#F2EEE6; --hatch:1 }
```
ตัวแปร CSS ส่งผ่านเข้า `<use>` ได้ ใช้ `style="opacity:var(--hatch)"` เปิดปิดลายเส้นแรเงา (pattern) ได้

## 4. การส่งต่อไปวาดจริง
ภาพที่วาดด้วยโค้ดเหมาะกับการร่างและเลือกทิศทาง แต่เส้นยังหยาบกว่าวาดมือ ต้องบอกผู้ใช้ตรงๆ และเสนอทางต่อ:
- **วาดเองใน Illustrator/Procreate**: ส่ง construction notes (สัดส่วน, ท่า, palette HEX, ความหนาเส้น, สิ่งที่ห้ามเปลี่ยน) + ภาพร่างเป็นพื้นหลังให้ trace
- **AI image (Firefly, Midjourney)**: เขียน prompt จากภาพร่าง เช่น
  `flat vector illustration of a cream white goose with an S-shaped long neck sitting on a front-load washing machine, orange beak and feet, dark green background, hand-drawn texture, minimal details drawn in background color, vintage children's book style, no text`
  แล้วนำผลมา Image Trace หรือวาดทับใน Illustrator
- **ส่งให้นักวาด**: สร้างชีตตัวละคร (หน้า/ข้าง/หลัง, 3 อารมณ์, palette, สิ่งที่ห้ามทำ)

## 5. บทเรียนจากงานที่ผ่านมา
- ผู้ใช้ไม่ชอบมาสคอตที่ดูการ์ตูนทั่วไปหรือ "น่ารักแบบเด็ก" (เป็ดใส่เสื้อ) แต่ชอบภาพประกอบที่มีเนื้อสัมผัสวินเทจ เช่น ภาพแกะไม้ ลายหมึก หรือห่านลายเส้นบนพื้นเขียวเข้ม
- ฟองสีขาวบนพื้นสีอ่อนจะหาย ต้องทำเวอร์ชันสีเข้ม
- ของในหน้าต่างเครื่องซักผ้าอาจดูเหมือนดวงตา ระวังรูปทรงที่อ่านผิดความหมาย
