# QA Checklist: ตรวจก่อนส่งภาพทุกครั้ง

เรนเดอร์ที่ scale 1 แล้วเปิดดู **ทุกแผ่น** ก่อนเรนเดอร์ scale 2 ส่งผู้ใช้ ทุกข้อในรายการนี้เคยพลาดมาแล้วในงานจริง

## ตัวหนังสือ
- [ ] ไม่มีตัวหนังสือล้นกรอบหรือถูกตัด (โดยเฉพาะหัวข้อใหญ่ในกรอบแคบ)
- [ ] ไม่มีตัวหนังสือทับกัน: สระบนและวรรณยุกต์ไทยชนบรรทัดบน (เพิ่ม line-height หรือ margin)
- [ ] ภาษาอังกฤษไม่ตกไปเป็น serif สำรอง (ฟอนต์ไทยที่โหลดแค่ไฟล์ thai ต้องมีฟอนต์อังกฤษนำหน้าใน font-family)
- [ ] ไม่ยืดช่องไฟภาษาไทยจนอ่านเป็นตัวๆ
- [ ] คำสะกดไทยและอังกฤษถูก ชื่อแบรนด์ตรงกับบรีฟ

## องค์ประกอบ
- [ ] ไม่มีชิ้นส่วนลอยผิดที่ (เช่น ขาป้ายไม่ติดป้าย, ของหลุดออกนอกกรอบ)
- [ ] ภาพหลักไม่ถูกตัดขอบโดยไม่ตั้งใจ (โดยเฉพาะ svg ที่ใหญ่กว่ากรอบ)
- [ ] รายละเอียดเล็กยังเห็นบนทุกสีพื้น (ฟองสีขาวบนพื้นอ่อนจะหาย)
- [ ] ทดสอบขนาดเล็ก 24–48px ถ้าเป็นโลโก้
- [ ] รูปทรงไม่ถูกอ่านผิดความหมาย (เช่น ของในหน้าต่างเครื่องดูเหมือนดวงตา, ขาเหมือนลูกศร)

## ความถูกต้องกับบรีฟและ ref
- [ ] ทุกคอนเซ็ปต์ระบุ ref ที่มา และวาง ref ไว้ข้างกัน
- [ ] ไม่มีไอคอนสามัญของธุรกิจเป็นฟอร์มหลัก และไม่มีสีสามัญของวงการ (ถ้าบรีฟไม่ได้ขอ)
- [ ] ฟอนต์และสีตรงกับ `brands/<brand>/ci.md` (ถ้ามีแล้ว)
- [ ] ไม่มีสไตล์ที่ผู้ใช้เคยปฏิเสธ (ดู `brands/<brand>/feedback-log.md`)

## ข้อมูลที่ใส่เอง
- [ ] ข้อความ ราคา เวลาเปิด เบอร์ หมายเลขเครื่อง หรือ handle โซเชียลที่ผู้ใช้ไม่ได้ให้ ต้องบอกผู้ใช้ว่าเป็นข้อความตัวอย่าง

## ไฟล์
- [ ] render.js ไม่มี WARN (request ล้มเหลว = ฟอนต์หรือรูปไม่โหลด)
- [ ] ตั้งชื่อไฟล์บอกลำดับและเนื้อหา เช่น `1-concept-A-....png`
- [ ] เก็บไฟล์ส่งผู้ใช้ในโฟลเดอร์ที่ผู้ใช้เปิดได้ (ไม่ใช่ scratchpad)
