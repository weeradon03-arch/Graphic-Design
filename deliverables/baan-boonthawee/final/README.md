# Baan Boonthawee / บ้านบุญทวี — ไฟล์ส่งมอบ CI v1.0

คู่มือฉบับเต็ม: `ci/BBT-CI-guidelines.pdf` (8 หน้า) · ภาพแต่ละหน้าอยู่ใน `ci/pages/`

## โครงสร้างไฟล์
```
logo/svg/   เวกเตอร์ เปิดแก้ใน Illustrator ได้ (ตัวหนังสือแปลงเป็น outline แล้ว ไม่ต้องลงฟอนต์)
logo/png/   PNG พื้นใส กว้าง 2000 px สำหรับงานออนไลน์/เอกสาร
ci/         คู่มือ CI (PDF + PNG ทีละหน้า)
source/     สคริปต์ที่สร้างโลโก้ (make_logo.py) และ HTML ของคู่มือ — สำหรับอ้างอิง/แก้ซ้ำ
```

## โลโก้ที่ใช้ได้ (มีแค่ 3 แบบ × 4 สี)
| ไฟล์ | แบบ | ใช้เมื่อ |
|---|---|---|
| `BBT-A-stamp-*` | A · สแตมป์อย่างเดียว | Line OA / โปรไฟล์โซเชียล, ไอคอน, ตรายาง, สติกเกอร์, ป้ายเลขห้อง |
| `BBT-B-vertical-*` | B · แนวตั้ง | ป้ายหน้าตึก, ปกเอกสาร, โปสเตอร์, โพสต์ |
| `BBT-C-horizontal-*` | C · แนวนอน | หัวกระดาษสัญญาเช่า, ใบเสร็จ, ป้ายแนวยาว, อีเมล |

| ท้ายชื่อไฟล์ | ใช้บน |
|---|---|
| `-color` | พื้นขาว/ขาวนวล (หลัก) |
| `-reverse` | พื้นดำ #1C1A17 (ป้ายกล่องไฟ, โปรไฟล์ดำ) |
| `-black` | งานพิมพ์สีเดียว, ตรายาง, ถ่ายเอกสาร |
| `-white` | ฟอยล์/สกรีน/แกะสลักสีเดียวบนพื้นเข้ม |

**Layer ใน SVG** (Illustrator เปิดเป็น layer ตามชื่อ): `paper` = พื้นในแสตมป์ · `ink` = กรอบ+ตึก · `light` = หน้าต่างไฟเปิด · `wordmark-en` · `wordmark-th` · (เวอร์ชันสีเดียวรวมเป็น `mark`)

## สี
| ชื่อ | HEX | RGB | CMYK* | ใช้กับ |
|---|---|---|---|---|
| INK หมึกดำอุ่น | #1C1A17 | 28 26 23 | 0 7 18 89 (พื้นใหญ่ใช้ Rich Black 60 40 40 100) | โลโก้, ตัวหนังสือ, พื้นเข้ม |
| PAPER ขาวนวล | #F5F2EC | 245 242 236 | 0 1 4 4 | พื้นหลัก |
| LAMP ไฟเหลืองอุ่น | #F7BC4B | 247 188 75 | 0 24 70 3 | หน้าต่างไฟเปิดเท่านั้น (ไม่เกิน 5%) |

\*CMYK แปลงจากค่าจอ ต้องปรู๊ฟกับโรงพิมพ์ก่อนพิมพ์จริง

## ฟอนต์ (ฟรี, Google Fonts, OFL)
- อังกฤษ: **Young Serif Regular** — ตัวพิมพ์ใหญ่ทั้งหมด, Tracking +140 — https://fonts.google.com/specimen/Young+Serif
- ไทย: **Trirong** — โลโก้/หัวข้อใช้ Medium 500, เนื้อหาใช้ Regular 400 — https://fonts.google.com/specimen/Trirong

## กติกาสำคัญ
- เว้นพื้นที่ว่างรอบโลโก้อย่างน้อย X ทุกด้าน (X = ความกว้างหน้าต่าง 1 บาน = 16% ของความกว้างสแตมป์)
- ขนาดเล็กสุด: A = 24 px / 8 มม. · B = 120 px / 30 มม. · C = 160 px / 40 มม.
- ห้าม: ยืด/บีบ, หมุน, เปลี่ยนสีไฟหรือเพิ่มสี, เพิ่มเส้นคั่น/กรอบ/เงา, วางบนพื้นลายหรือสีกลาง, พิมพ์ชื่อใหม่ด้วยฟอนต์อื่น
- ข้อความ ที่อยู่ เบอร์โทร และคำว่า "สัญญาเช่าห้องพัก" / "204" ในหน้าตัวอย่างการใช้งานเป็น **ข้อความตัวอย่าง**

## หมายเหตุสำหรับคนทำต่อ
- เส้นสั่นแบบลายมือถูกฝังเป็นจุดในเวกเตอร์แล้ว (ไม่ใช่ฟิลเตอร์) จึงพิมพ์/ตัดสติกเกอร์/ทำป้ายได้ตรงตามไฟล์ ถ้าต้องการให้เส้นนุ่มขึ้นใน Illustrator ใช้ Object › Path › Simplify
- อยากได้โลโก้ขนาดหรือสีอื่น ให้ export จาก SVG ไม่ต้องวาดใหม่
- สร้างใหม่ทั้งชุด: `python make_logo.py <โฟลเดอร์ fonts ของ fontsource> <ปลายทาง> 500` (ต้องมี shapely, fonttools, brotli, uharfbuzz)
